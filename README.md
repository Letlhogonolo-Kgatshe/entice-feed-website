# Entice Feed: Agri-SaaS Landing Page

![HTML](https://img.shields.io/badge/HTML5-E34F26) ![Tailwind](https://img.shields.io/badge/Tailwind%20CSS-38B2AC) ![Chart.js](https://img.shields.io/badge/Chart.js-FF6384)

A marketing website for **Entice Feed Pty Ltd**, a South African agricultural Software-as-a-Service start-up whose platform connects farmers, buyers and partners across the agricultural value chain.

**Live:** https://letlhogonolo-kgatshe.github.io/entice-feed-website/

![Entice Feed homepage](docs/screenshot.jpg)

## What's on the page

- A hero section with the value proposition and a link to the investor deck
- Impact metrics: efficiency, partner organisations, farmers connected and yield improvement
- Feature sections for the ecosystem, AI solutions, auctions and plant tracking
- **Chart.js** visualisations of platform data
- A contact section and an investor login entry point
- Responsive layout with a fixed navigation bar

## Tech

A single `index.html` built with **Tailwind CSS** (CDN), **Chart.js** and custom CSS. There's no build step.

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
npx http-server .
```
